# WebDigital — одностраничный сайт студии

Основная версия теперь собрана напрямую в HTML/CSS/JavaScript без Figma. Это короткая продающая страница в тёмной editorial-системе: крупная типографика, редкий красный акцент, светлые контрастные секции и функциональный калькулятор.

Исходник дизайн-концепции для малого бизнеса на российском рынке: лендинги от 30 000 ₽, интернет-магазины от 68 000 ₽, сайты услуг, поддержка и базовое SEO.

## Активная страница

- `index.html` — вся воронка на одной странице: оффер, форматы, работы, калькулятор, процесс и заявка.
- `styles.css` и `modern.css` — дизайн-система, адаптив и анимации.
- `calculator.js` — пересчёт цены и сроков.
- `site.js` — reveal-анимации, параллакс, курсор и состояние формы.
- `case-kora.html` — кейс интернет-магазина KORA RND.
- `case-palitra.html` — кейс лендинга сервисного центра «Палитра».
- `case-dkmoto.html` — концептуальный кейс DKMOTO с пометкой о закрытом превью.
- `case-pride.html` — кейс корпоративного сайта Agency Pride.
- `case-detail.css` и `case-detail.js` — общая glass-система и анимации страниц кейсов.

## Материалы проекта

- `cases.html` — каталог из четырёх кейсов.
- `case.html?case=palitra` — лендинг сервисного центра «Палитра».
- `case.html?case=kora` — интернет-магазин KORA RND.
- `case.html?case=dkmoto` — карточка проекта DKMOTO; публичное превью пока защищено Vercel Authentication.
- `pricing.html` — предыдущая отдельная версия страницы цен; из новой навигации не используется.
- `competitive-analysis.html` — конкурентный анализ восьми средних студий и стратегия сайта на 90 дней.
- `research/` — клиентский аудит, отбор конкурентов, подробные профили и проверка качества отчёта.

В кейсах не заявляются неподтверждённые показатели продаж. Структура «Палитры» и KORA описана по доступным версиям сайтов; карточку DKMOTO нужно дополнить после открытия публичного превью.

## Концепция

- Позиционирование: продуктовая разработка с SEO-архитектурой и аналитикой до дизайна.
- Основной CTA: получить диапазон бюджета.
- Вторичный CTA: посмотреть релевантные кейсы.
- Визуальный язык: editorial-типографика, тёмные технологические панели, бирюзовый системный акцент, оранжевый коммерческий акцент.
- Макет содержит desktop и responsive mobile состояния.

## Локальный просмотр

Откройте `index.html` через локальный HTTP-сервер. В проекте нет внешних зависимостей или изображений.

## Публикация

Сайт подготовлен для GitHub Pages и публикуется напрямую из корня ветки `main`.

## Важно

Числа в демонстрационном кейсе — placeholders, явно помеченные в интерфейсе. Перед публикацией их нужно заменить подтверждёнными показателями реального проекта.
